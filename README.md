# Nasna - Together we grow

Humanitarian aid management platform for connecting displaced individuals in Lebanon with NGO and government support.

## Stack

- React 18 + Vite
- Material-UI 6
- Firebase (Firestore, Auth, Hosting)
- Redux Toolkit + redux-persist
- i18next (EN, AR, FR)

## Setup

```bash
yarn install
yarn start
```

## Deploy

```bash
yarn deploy
```
